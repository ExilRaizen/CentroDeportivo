# Centro Deportivo Alex Retamal Lobos

Landing informativa del centro deportivo (futbolito y pádel, Rancagua). React + Vite + Tailwind CSS.

## Desarrollo

```bash
npm install
npm run dev
```

## Datos editables

Teléfono de WhatsApp, dirección, horario, Instagram, mapa y precios están en `src/data/site.js`.
Cuando exista el número, se completa `whatsapp` (ej: `56912345678`) y los botones abren el chat automáticamente.

## Build

```bash
npm run build
```

Genera la carpeta `dist/` lista para publicar en cualquier hosting estático (Netlify, Cloudflare Pages, etc.).
